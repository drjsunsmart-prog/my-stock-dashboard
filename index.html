ⓘ 사용 안내 — 위 버튼은 Yahoo Finance 비공식 API에서 VIX·S&P 500 실시간 데이터를 가져옵니다.
브라우저 보안 정책(CORS)으로 인해 로컬 파일(file://)에서는 직접 호출이 차단될 수 있습니다.
✅ 해결법 ① : VS Code의 Live Server 확장으로 로컬 서버(http://localhost)에서 열기
✅ 해결법 ② : python -m http.server 8080 실행 후 http://localhost:8080 에서 열기
✅ 해결법 ③ : 파일을 웹 서버(GitHub Pages, Netlify 등)에 업로드 후 접속
공포·탐욕 지수는 VIX를 기반으로 근사 산출하며, 나머지 세부 지표는 VIX·S&P 500에서 파생합니다.
